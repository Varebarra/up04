HelpDesk — практические работы №7 и №8

Проект WPF на C# для Visual Studio 2026.

Запуск:
1. Распакуйте архив.
2. Откройте HelpDesk.slnx в Visual Studio 2026.
3. Убедитесь, что установлен компонент «Разработка классических приложений .NET».
4. Запустите проект клавишей F5.

Данные для временной авторизации:
Логин: admin
Пароль: 12345

В проекте реализованы требования практических работ №7 и №8:
- структура Views, Models, Data, Services, Helpers;
- LoginWindow, MainWindow, TicketCreateWindow, TicketEditWindow;
- модели User и Ticket, пустые классы Category, Status, Priority;
- пустые заготовки Database и AuthService;
- временная авторизация;
- проверка пустых полей;
- тестовые заявки в List<Ticket>;
- DataGrid с вручную заданными столбцами;
- поиск по описанию, категории и статусу;
- фильтр статуса и совместная работа поиска с фильтром;
- добавление, редактирование и подтверждение удаления;
- выход из системы;
- три улучшения интерфейса: подсказка поиска, счётчик заявок, двойной щелчок для редактирования.

MS SQL Server и ADO.NET не подключены — по условиям практических работ №7 и №8 это пока не требуется.
